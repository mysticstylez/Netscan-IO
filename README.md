Netscan IO is a basic Android network scanner without all the bloat. NSIO will never ask for personal information, a login, and will track 0 data from the user. 
Feel free to edit and use as you wish for personal use only. Not for commercial/retail use.

Prerequisites:
JDK 17 https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html

Setup:

Install JDK 17 into the .tools directory
Import project into Android Studio

Build
